# 本地 PGO 原始采样缓存

所有平台共用 100 MiB（104857600 字节）的本地 `.profraw` 容量上限。启动时整理旧版本遗留数据；新采样写出后再次整理。只要总量超过上限，就按文件修改时间从旧到新删除，直到严格低于上限。初始恰好等于上限时不主动删除。

缓存目录为平台临时目录下的 `MusicMapMaker`：Windows 使用 `%TEMP%/MusicMapMaker`，桌面类 Unix 使用平台临时根，Android 使用本包私有 `cache/MusicMapMaker`。预算跨应用版本累计，不按版本分别计算。只统计直属普通 `.profraw` 文件，资源 ZIP、`.profdata`、子目录与符号链接不参与清理。

正在上传的当前文件计入总量但暂时保护；上传完成或失败后解除保护，继续未完成的严格淘汰目标。单份大于或等于容量上限的采样也可能在上传结束后被淘汰。拒绝上传或会话过短时同样整理本地文件，上传授权不影响容量上限。非插桩构建启动也会整理以前积累的原始采样。

显式写出使用 LLVM 的完成标记，防止退出自动写盘重新生成已淘汰的文件。所有扫描、排序和删除均处于启动或退出低频路径。删除前复核类型、大小与修改时间；活动文件变化、权限或文件锁导致无法完成时记录警告，不能虚报已经释放的空间。本规则只整理客户端缓存，不删除上传服务器保存的样本。
